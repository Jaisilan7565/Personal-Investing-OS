# Personal Investing OS - All In One Guide

## Vision

A production-ready MERN application focused on investing discipline, learning, reflection, and behavioral analytics for Groww users.

## Core Principles

Education over execution, reflection over reaction, discipline over frequency, and long-term thinking.

## Tech Stack

React 18, Vite, TypeScript, Tailwind CSS, TanStack Query, Redux Toolkit, Formik, Yup, Node.js, Express.js, MongoDB Atlas, Mongoose, JWT.

## Modules

Dashboard, Daily Journal, Learning Tracker, Watchlist, Decision Log, AI Mentor.

## Analytics

Emotion trends, discipline score, learning momentum, bias detection.

## Charts

Emotion pie chart, discipline trend line chart, learning progress bar chart using Recharts.

## Backend

Controller-Service-Model architecture with JWT authentication and Zod validation.

## AI Prompt Rules

Education-first, no predictions, no financial advice, calm mentoring tone.

## Security

bcrypt password hashing, JWT expiry, rate limiting, environment variables.

## Execution Guide

Generate backend first, then analytics, frontend dashboard, and AI integration.

## Master Build Prompt

Build a scalable MERN application called Personal Investing OS.  
Use React 18 + Vite + TypeScript + Tailwind CSS + TanStack Query + Redux Toolkit + Formik + Yup.  
Use Node.js + Express.js + MongoDB Atlas + Mongoose + JWT authentication.  
Add analytics dashboards and charts using Recharts.  
Include AI mentor features focused on investing discipline and learning.  
Do not include trading execution or stock predictions.  
Follow production-grade architecture and best practices.
